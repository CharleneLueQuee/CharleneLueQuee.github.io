Personal Project

Operation: Last Signal 🌐☢️

A self-directed Cisco Packet Tracer network simulation built entirely from scratch — set in a post-apocalyptic world where network infrastructure is the difference between survival and collapse. Each scenario is a real networking and GRC challenge wrapped in a story-driven context. Est. completion: ~2 weeks.

🏕️

Scenario 1 — Refugee Camp Comms

Network Design · DHCP · Wireless

A refugee settlement of 200+ survivors needs internet access coordinated through a single router. Configure DHCP, set up wireless access points, and segment medical, operations, and public zones — because in a crisis, network access is a humanitarian issue.

DHCPWirelessSegmentation
📡

Scenario 2 — Rogue Signal Detection

Network Monitoring · ACLs · Threat Detection

An unknown device is broadcasting on the survivor network — possibly a faction spy or a compromised node. Use ACLs, NetFlow analysis, and MAC address tracking to identify and isolate the rogue signal before it leaks your location.

ACLNetFlowMAC Tracking
🏚️

Scenario 3 — Fallout Shelter IoT Security

IoT · Physical Security · Hardening

The underground shelter is running on IoT sensors — radiation monitors, door locks, and emergency lighting. A power surge corrupted configurations. Re-secure the IoT network, reset device credentials, and implement a hardening checklist before the next threat arrives.

IoTHardeningPhysical Security
🔐

Scenario 4 — The Encrypted Broadcast

Cryptography · SSH · Data Integrity

A resistance leader needs to broadcast encrypted orders to outposts across the wasteland without interception. Configure SSH-only access, establish encrypted data channels, and hash all outgoing messages to verify integrity on arrival.

SSHHashingEncryption
🗺️

Scenario 5 — The Last Router Standing

Routing · NAT · Network Recovery

Only one router connects three survivor factions to the outside world. Configure NAT so all factions share one public IP, set up routing between their private subnets, and document a recovery plan in case this final node goes down.

NATRoutingRecovery Plan

Why This Project Matters for GRC

Self-directed learning · NIST CSF · Risk Thinking

Every scenario in Operation: Last Signal maps directly to a real-world GRC control from NIST CSF or ISO 27001. The apocalypse setting strips away corporate jargon and forces you to think about why controls exist — because when resources are scarce and stakes are high, only the essential security principles survive.
